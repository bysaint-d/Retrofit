# Retrofit

Android Java example fetching cryptocurrency data with Retrofit, Gson, RxJava and RecyclerView.

## Stack

Java · Android SDK · Gradle · Retrofit · Gson · RxJava

## Run locally

1. Clone this repository.
2. Open the project root in Android Studio.
3. Install the Android SDK requested by the Gradle configuration and finish Gradle sync.
4. Run the app on an emulator or device with Android API 28 or newer.

## Project layout

- `app/src/main/java/` — application source.
- `app/src/main/res/` — layouts and resources.
- `app/build.gradle` — app configuration and dependencies.

This repository is a learning example.
